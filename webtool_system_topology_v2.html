📡 地理编码精度 — 三层级联架构 ✅ 已实现

🔀 级联逻辑

1
MapShare VIC PRIMARY
api.mapshare.vic.gov.au
DEECA 官方 ArcGIS Geocode Server
数据源：GNAF + Vicmap Address（每月更新）
精度：<5m · 覆盖：全维州 · 无需 API Key
score ≥ 60 才采用 · 最多返回 8 候选
2
Nominatim FALLBACK
nominatim.openstreetmap.org
OSM 众包数据 · countrycodes=au
精度较低，新开发地块可能缺失
仅在 Tier 1 返回 0 结果时触发
3
Photon / komoot LAST RESORT
photon.komoot.io
Victorian bbox 限制（140.9–149.9°E）
GeoJSON 返回 · 维州外结果被过滤
仅在前两层均失败时触发

🔧 MapShare 特殊处理

osmType: null — 跳过 OSM 节点查找
osmId: null — terrain_engine 直接走 Vicmap WFS
score ≥ 60 过滤低质量候选
AbortSignal.timeout(8000) 防超时
.catch(() => []) 单层失败不中断级联
坐标系：WGS84 (EPSG:4326) 统一输出
结论：MapShare VIC 是维州地址→地块数据管道的最优免费方案。官方政府 API，无速率限制说明，GNAF 月更，无需注册。

🔄 完整数据流 — 从地址输入到报告输出

1
用户输入维州地址
SiteInvestigationPanel · debounce 300ms → fetchSuggestions() · 3-tier geocoder cascade
↓
2
地理编码 → 坐标
MapShare VIC (primary) → Nominatim (fallback) → Photon (last resort)
返回 lat/lon/osmType/osmId/suburb/source
↓
3
地形分析 (terrain_engine)
Vicmap WFS → 地块多边形 → area/frontage/depth
OpenTopoData → 坡度/海拔 · deriveDimensions 2°旋转步长优化
↓
4
区位评分 (location_engine)
Overpass API 500m 半径 → 学校/医院/交通/商业
权重评分 → LocationScoreCard 展示
↓
5
文档上传 → 字段提取 (unified_engine)
Section 32 / Permit / Planning Report → regex 解析
zoneCode / overlays / covenants / dealingNumbers → store.batchDispatch()
↓
6
财务计算 (live_calc_engine)
stamp duty + construction + contingency + holding interest → totalCost
IRR: Newton-Raphson 月度现金流 (irr_engine) · 实时边距
↓
7
敏感性分析 (sensitivity_engine)
5×5 GRV/Cost ±10% 热力矩阵 · margin = profit/GRV×100
InsightPanel SensitivityMatrix 展示
↓
8
战略洞察 (insight_engine)
墨尔本行业阈值规则 → Risk Level / Confidence Score
Red Flag / Opportunity / Recommendation
↓
9
多情景比较 (comparison_engine)
Store multi-scenario → strategy matrix → ComparisonPanel
↓
10
导出报告 (export_engine)
PDF (jsPDF CDN) / CSV / JSON · 包含空间/规划/区位全量数据
